# Formula 1 Machine Learning

Predict Formula 1 race outcomes from the public Kaggle F1 dataset. The project
takes you from raw CSVs to trained models and predictions in three commands.

## What's in the box

- **Race winner predictor** — XGBoost binary classifier producing per-driver
  win probabilities normalized within each race.
- **Podium predictor** — top-3 probability per driver.
- **Lap pace regressor** — predicts median per-lap pace in milliseconds and
  ranks drivers within a race.
- **Feature engineering** that is strictly leak-free: every feature for race
  *r* is computed from races strictly before *r* (career and rolling
  driver/constructor/circuit stats, qualifying times, circuit pace baseline).
- **Static + interactive visualizations** (matplotlib/seaborn + Plotly).
- **CLI scripts** for the full clean → features → train → predict flow.
- **Demo notebook** (`notebooks/demo.ipynb`) that walks through everything.

## Project layout

```
src/
    data/data_cleaner.py        load + clean the 14 raw CSVs
    features/                   driver/constructor/circuit features + builder
    models/                     race winner / podium / lap-pace models
    visualization/              static + interactive plots
    utils/                      logger, paths, config loader, I/O helpers
scripts/
    clean_data.py               raw CSVs → cleaned tables
    build_features.py           cleaned tables → modeling frame
    train_models.py             features → 3 saved .joblib models + metrics.json
    predict_race.py             predictions for a held-out race
notebooks/demo.ipynb            full end-to-end walkthrough
data/raw/                       Kaggle CSVs (already included)
data/interim/, data/processed/, data/models/  generated by the pipeline
```

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 1. Clean raw CSVs → data/interim/*.parquet
python scripts/clean_data.py

# 2. Build the (race, driver) feature table → data/processed/features.parquet
python scripts/build_features.py

# 3. Train all three models → data/models/*.joblib + metrics.json
python scripts/train_models.py

# 4. Predict the most recent race
python scripts/predict_race.py            # or: --race-id 1144
```

Or open `notebooks/demo.ipynb` and run the cells in order.

## Configuration

`config.yaml` holds tunable knobs (paths, `min_year`, train/test split, XGBoost
hyperparameters). The CLI scripts read it through `src.utils.load_config()`.

## Data

The raw CSVs in `data/raw/` come from the
[Kaggle Formula 1 World Championship dataset](https://www.kaggle.com/datasets/rohanrao/formula-1-world-championship-1950-2020).
